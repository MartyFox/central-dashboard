How to read these results

Counts include all reported severities after exceptions. They are not blocking-policy counts. Application counts are open CodeQL alerts in configured languages; dismissed alerts are excluded. No reported findings does not prove complete coverage. Missing counts are never treated as zero. Combined counts are unavailable when a configured scanner has no results. Repository highlighting reflects the highest known severity across all finding types, even when filters select a different type or another scanner is unavailable. It is not a pass/fail policy decision.
